# Children Story Pipeline

面向幼教行业人员的 3–6 岁原创故事创作与质量审核 Skill。它把大模型常见的“看起来像故事、却不适合幼儿”的输出，转成可检查、可返修的创作流程。

> 适用对象：幼儿园教师、园所课程与教研人员、儿童内容编辑、绘本及动画创作者。

## 它解决什么问题

通用大模型能很快生成一篇“儿童故事”，但通常无法稳定完成下面三类关键工作：

### 1. 把幼儿真实能理解和经历的事情，写成一个完整故事

常见卡点是主题很正确、语言也可爱，但故事变成知识讲解、品德说教，或只是角色依次出现。这个 Skill 先锁定一个儿童可经历的核心发现，再用 `Story Spine`、因果链和完整 8 Beat 组织冲突、尝试、反馈与结局，让故事真正发生。

### 2. 让角色靠自己的性格推动故事，而不是充当台词容器

大模型常把角色写成可互换的名字，或让成人式“答案机器”直接解决问题。Skill 的角色因果检查要求每位主要角色都有不可替代的行动和后果，并保留原有性格、只调整方法；用 `REMOVE / SWAP / CONSEQUENCE` 三项测试识别无效角色。

### 3. 同时守住适龄、安全、事实与连续性

3–6 岁故事不能只追求文句顺滑：是否可模仿、物体状态是否前后一致、因果是否成立、自然或健康知识是否夸大，都会影响实际使用。Skill 在成稿后进行一致性与完整性审核；涉及可核验知识时要求标明来源和表达边界，并把问题退回最早出错的环节修复。

## 核心能力

- 自然语言 Story Brief，默认聚焦一个核心儿童经验
- 角色因果与不可替代性检查
- 6 类通用 Story Engine、Story Spine 与 Causal Chain
- 完整 8 Beat Story Master 与三轮写作
- 教育不说教：教育意图通过行动、选择和结果呈现
- 事实真实性、变量、物体状态与儿童模仿安全硬审计
- Story Consistency Check、回归修复与 Current Effective Artifact
- 绘本 / 动画 Adaptation Handoff

## 两种模式

- `STANDALONE`：没有 IP 设定也可直接用于单篇故事创作。
- `CANON_AWARE`：接入角色圣经、世界观、地点或历史故事时，额外执行一致性约束。

## 使用方式

将本目录作为 Skill 安装或放入你的 Skill 工作区。提交自然语言故事需求后，Skill 按 Stage 0–6 生成并审核故事；若你希望在 Brief、角色、故事母版或审核后暂停，可直接用自然语言说明。

详细执行规则见 [SKILL.md](SKILL.md)，可复用模板位于 [templates](templates)，审核与写作参考位于 [references](references)。

## 边界

这是一套创作与质量审核流程，不替代教师、教研人员或监护人对教育目标、事实来源和儿童实际反应的专业判断。其产出在正式使用前仍应进行人工审阅与试读。
